# AutoSRE 架构设计

## 系统概览

AutoSRE 采用多 Agent 协作架构，通过消息总线实现 Agent 间通信，由编排器统一调度。

## Agent 角色

| Agent | 职责 | 输入 | 输出 |
|-------|------|------|------|
| 告警收敛 Agent | 聚合相似告警 | 原始告警 | 告警组 |
| 日志分析 Agent | 提取异常模式 | 告警组 | 错误模式 |
| 指标查询 Agent | 查询系统指标 | 告警组 | 指标数据 |
| 根因推理 Agent | 推断根因 | 日志+指标 | 根因假设 |
| 修复执行 Agent | 执行修复 | 根因 | 修复结果 |
| 报告生成 Agent | 生成报告 | 全部数据 | 复盘报告 |

## 数据流

Alertmanager -> API -> 编排器 -> Agent1 -> Agent2 -> ... -> 报告+通知

## LLM 集成

使用 DeepSeek V4 Flash 进行深度分析，与规则推理互补。
